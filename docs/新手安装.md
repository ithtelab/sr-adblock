# 新手安装教程（从零开始，跟着点就行）

这份教程假设你**没接触过小火箭**。全程只有复制链接、粘贴、点几下，不需要懂技术。

先花 10 秒确认你属于哪种情况，然后**只看你那一节**：

| 你的情况 | 看哪节 | 装完的效果 |
| :-- | :-- | :-- |
| **A. 我刚买小火箭，还没有节点** | [第 3 节](#情况-a全新一套还买了节点订阅) | 不翻墙，只去广告 |
| **B. 我已经有节点订阅，小火箭能正常上网** | [第 2 节](#情况-b有节点订阅但配置是机场给的) | 照常上网 + 去广告 |
| **C. 我想要三件套都装上**（最完整） | [第 4 节](#情况-c要最完整的去广告域名层--模块层) | 上网 + 完整去广告 |

> 如果点表格里的链接没反应（GitHub 网页版对长文档是边滚边加载的，偶尔跳不过去），
> 直接往下滚就行 —— 每一节的标题都以**「情况 A」「情况 B」「情况 C」**开头，很好找。

## 第 0 步：先得有小火箭（没有的话从这看）

Shadowrocket（小火箭）是付费 App，**中国区 App Store 没有**，必须用美区 Apple ID 买，价格 1.99 美元。

需要准备：**美区 Apple ID**（免费的，自己注册即可）+ **美区礼品卡充值**（淘宝/发卡网站买，用支付宝付）。

详细买法搜索引擎上有大量教程，也可以看 [yfamilys.com/manual](https://yfamilys.com/manual) 的「前期准备」。

装好之后打开小火箭，先别急着配置，往下看。

## 情况 A：全新一套（还买了节点订阅）

> 你有节点订阅链接（一般是 `https://xxx.com/api/v1/client/subscribe?token=...` 这种）。

### 1. 加节点

1. 打开小火箭，点底部 **「首页」**
2. 右上角 **`+`** → 把**节点订阅链接**粘进去 → 右上角「完成」
3. 稍等几秒，下面会出现一串节点名字（香港、日本、美国……）

### 2. 加配置（这就是"去广告规则"）

1. 点底部 **「配置」**
2. 右上角 **`+`** → 粘贴这一行 → 点「下载」

   ```
   https://raw.githubusercontent.com/ithtelab/sr-adblock/release/conf/base.conf
   ```

3. 下载完，**点一下这条配置**（让它打上勾，变成「使用配置」）

### 3. 连上试试

1. 回「首页」，右上角开关打开（会提示添加 VPN 配置，点「允许」，输密码）
2. **「全局路由」选「配置」** ← 这步很关键，不选这个规则不生效
3. 随便打开一个 App 试试网络通不通

### 4. 只看去广告（先不装证书）

现在去广告**已经生效了**（域名层不需要证书）。用几天，看看有没有 App 出问题。
没问题、而且你想干掉开屏广告 → 接着看[情况 C](#情况-c要最完整的去广告域名层--模块层)。

## 情况 B：有节点订阅，但配置是机场给的

> 你现在的配置能用，只是广告多。**不需要换配置**，只要往里面加两行。

### 1. 打开你的配置

1. 小火箭 → 底部 **「配置」**
2. 找到正在用的那条（有勾的）→ 点右边的 **`ⓘ`**
3. 点 **「编辑纯文本」**

### 2. 加两行

在 `[Rule]` 这一行的**下面**，粘进去这两行：

```
DOMAIN-SET,https://raw.githubusercontent.com/ithtelab/sr-adblock/release/ruleset/ad-domain.list,REJECT
RULE-SET,https://raw.githubusercontent.com/ithtelab/sr-adblock/release/ruleset/ad-rule.list,REJECT
```

粘完点右上角「保存」。

> ⚠️ 一定要放在 `[Rule]` 段里，而且**要在 `FINAL` 那一行前面**（`FINAL` 是兜底规则，
> 放在它后面就没机会生效了）。

### 3. 断开重连一次

回「首页」，把开关关掉再打开。

**完成。** 这就是最简单的用法 —— 只装域名层，不碰证书。

> 以后想让规则自动更新：点「配置」→ 点配置右边的 `ⓘ` → 打开「自动更新」。
> 或者把小火箭的「后台 App 刷新」打开（iOS 设置 → 通用 → 后台 App 刷新）。

## 情况 C：要最完整的去广告（域名层 + 模块层）

> 模块层能干掉**开屏广告**和改响应体能去掉的广告，比只拦域名狠得多。
> 代价是：要给小火箭装一个证书、开 HTTPS 解密；极少数 App 会因此报错或无法登录。

**先确认你已经完成了情况 A 或情况 B**（配置能用、域名层已生效），再来做这节。

### 1. 装证书（只有模块层需要）

1. 小火箭 → 底部 **「配置」** → 点正在用的配置右边的 **`ⓘ`**
2. 找到 **「HTTPS 解密」** → 点 **「生成新的 CA 证书」** → 点 **「安装证书」**
   - 如果要输密码，输 `Shadowrocket`
3. 现在会跳到 iOS 设置 → **「已下载描述文件」** → 右上角「安装」→ 输锁屏密码 → 再点一次「安装」
4. **最关键的一步**：iOS 设置 → **「通用」** → **「关于本机」** → 拉到底 → **「证书信任设置」**
   → 找到 `Shadowrocket` → **把开关打开**（变绿）

> ⚠️ **第 4 步不做，前面全白做。** 「装了证书但没开完全信任」是"装了没用"的头号原因。

### 2. 装两个模块

1. 小火箭 → 底部 **「配置」** → 找到 **「模块」**（不同版本可能在配置页里往下滚）
2. 右上角 **`+`** → 粘贴第一条 → 完成
3. 再点 `+` → 粘贴第二条 → 完成

   ```
   https://raw.githubusercontent.com/ithtelab/sr-adblock/release/module/ads-all.srmodule
   https://raw.githubusercontent.com/ithtelab/sr-adblock/release/module/httpdns.srmodule
   ```

4. 确认两个模块的开关都是**打开**状态
5. 回「首页」，把 VPN 开关关掉再打开

### 3. 有个 App 打不开了怎么办

**不要慌，也不要急着卸载**，按这个顺序试：

1. 打开本仓库的 [`lookup` 工具说明](../README.md#-出问题了怎么办)，或者直接在聊天里告诉我"某某 App 打不开"
2. **大概率是这个 App 有证书校验**（银行、券商居多）→ 装第三个模块，把它排除在解密之外：
   ```
   https://raw.githubusercontent.com/ithtelab/sr-adblock/release/module/mitm-exclude.srmodule
   ```
   装完把它**拖到模块列表最下面**，点它的「编辑参数」，填进去 `-app的域名.com`（前面那个减号是"排除"的意思）
3. 实在搞不定 → 简单粗暴但有效：**把模块全部关掉**，只留域名层（就是情况 B 的状态）。域名层已经能拦掉大部分广告了。

## 银行 / 券商 / 支付 / 办公 App 怎么排除

这类 App 不要解密（它们有证书校验，解密后会登录失败、白屏、强制退出）。**三种办法，从省事到彻底**：

**办法一：装「排除解密」模块（推荐，什么都不用填）**

```
https://raw.githubusercontent.com/ithtelab/sr-adblock/release/module/mitm-exclude.srmodule
```

装上后**拖到模块列表的最下面**（顺序不对可能不生效）。它已经预置了 45 个域名，
覆盖常见银行（工行/建行/农行/中行/交行/招行/邮储/浦发/兴业/民生/平安/广发/光大/中信…）、
券商（东方财富/富途/华泰/中信证券/招商证券/同花顺/雪球…）、支付（支付宝/财付通/银联）、
办公（钉钉/飞书/WPS/石墨/Zoom/Slack）。

**想再加自己的**：点这个模块的「编辑参数」，在「额外排除」里填 `-你的域名.com`
（前面那个减号是"排除"的意思），多个用英文逗号分隔。

> ⚠️ 被排除的域名**不做解密** → 依赖解密的重写类去广告对它们无效。
> 比如东方财富在预置名单里，所以它的开屏广告那条重写规则不会生效（域名层照样拦它的广告域名）。
> **要某个 App 的去广告效果，就得把它的域名从名单里删掉**（见办法三）。

**办法二：只用 per-App 模块（最彻底）**

不要装总模块，只装你在意的几个 App 的模块 —— **没装的 App 就不会被解密**。
这是隐私上最干净的做法，解密范围从上千个主机名降到几个。

**办法三：自己改名单（需要重新构建）**

改仓库里的 `config/mitm-exclude.txt`（一行一个域名，可以加注释），
然后跑一次构建（或等每天自动重建）。删掉某一行 = 那个 App 恢复解密、去广告生效。

**办法四（可选）：让它连代理都不走**

在 `base.conf` 的 `[General]` 段里 `skip-proxy` 后面加上域名（逗号分隔）。
这比"排除解密"更彻底 —— 那些域名**完全不经过小火箭**，既不解密也不拦广告。
适合"绝对不想让工作流量碰到小火箭"的场景。`base.conf` 里已经预置了
`*.ccb.com,*.abchina.com.cn,*.psbc.com` 三家银行。

## 怎么知道它真的在干活

**方法一**：打开一个有开屏广告的 App（比如某天气、某团购）。开屏广告消失了 = 生效。

**方法二（推荐）：看代理日志 —— 这是排查问题最有用的一步**

先打开日志开关：**「数据」→「代理」→ 打开「启用日志记录」**

然后去复现问题（比如打开那个还有广告的 App），再回来看：

**「数据」→「代理」** 页面就是请求日志。每条记录包含四件事：

| 看到的内容 | 意思 |
| :-- | :-- |
| **请求 URL** | 这个请求打到了哪个域名 —— **这就是你要找的广告域名** |
| **匹配的规则策略** | 显示 `REJECT` = 被拦了；显示 `PROXY`/`DIRECT`/`FINAL` = **没被拦**（所以广告还在） |
| **传输协议** | 走的是 HTTP 还是 HTTPS |
| **有没有 `MITM` 标记** | 有 = 这个域名正在被解密（模块的重写规则能生效）；没有 = 没解密（重写规则一定不生效） |

> **怎么用它定位"为什么广告还在"**：
> - 日志里那条广告请求显示 `DIRECT` 或 `PROXY` → **这个域名没被任何规则拦住**，是漏网域名
> - 显示 `REJECT` 但广告还在 → 是 App 把广告缓存在本地了（清缓存）或者广告换了别的域名
> - 显示请求了某个域名但**没有 MITM 标记** → 这一条要靠模块的重写去广告，但没解密，所以模块的规则没生效

**方法三（最快的一键修复）：不用改任何文件**

在日志里点开那条广告请求 → 右上角 **`•••`** → **「添加规则」** →
小火箭会让你直接把它的域名加成一条拦截规则。**这是最省事的办法**，
看到哪个域名不顺眼就加哪个，不用等规则更新。

**方法四**：确认配置的规则集有没有下载成功

小火箭 → 配置 → 点配置右边的 `ⓘ` → 找 **「规则集URL」**，看里面几条是不是打勾状态。
如果是 ❎（下载失败），点一下重新下载。

## 拉不下来 / 加载失败？

`raw.githubusercontent.com` 在国内经常连不上。三个办法，从简单到麻烦：

1. **先重试**：小火箭请求这些链接时本来就会走自己的隧道，节点通就能拉到。加载失败就点重新下载。
2. **换镜像链接**：把链接里的
   `raw.githubusercontent.com/ithtelab/sr-adblock/release/`
   整个替换成 `cdn.jsdelivr.net/gh/ithtelab/sr-adblock@release/`
3. **本地导入**：用电脑/手机浏览器打开链接，把内容存成文件，再用小火箭的「从文件导入」。

## 情况 D：没有节点、也不想搞代理，只想纯去广告

那上面第 0 步的小火箭还是要买（去广告功能在小火箭里），但**不需要节点**。

做法：新建一个只有去广告的配置 —— 把下面这段完整复制，存成 `adonly.conf`，
然后小火箭 → 配置 → `+` → 选择从文件导入：

```
[General]
bypass-system = true
dns-server = https://doh.pub/dns-query,223.5.5.5
ipv6 = false

[Rule]
DOMAIN-SET,https://raw.githubusercontent.com/ithtelab/sr-adblock/release/ruleset/ad-domain.list,REJECT
RULE-SET,https://raw.githubusercontent.com/ithtelab/sr-adblock/release/ruleset/ad-rule.list,REJECT
FINAL,DIRECT

[MITM]
```

导入后点它使用，回「首页」把「全局路由」选成**配置**，打开开关。这样不翻墙但广告会被拦掉。

> 注意：这版**不含模块层**（去开屏广告需要证书），只有域名层。
