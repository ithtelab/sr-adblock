# ============================================================================
#  域名层 放行名单（allowlist）—— 修正误杀
#
#  语法：
#    foo.com        放行 foo.com 及其所有子域（最常用）
#    *.foo.com      只放行子域，foo.com 本身仍拦截
#    !keep          以 ! 开头表示"强制保留"被上游误标的……（保留给以后扩展）
#    # 开头为注释，空行忽略
#
#  工作方式：
#    构建时把这些域名从合并结果里剔除，并在生成的配置里于规则集**之前**
#    插入对应的 DIRECT 规则（小火箭从上到下匹配，所以上面的规则优先）。
#
#  怎么加：手机上和实际使用中发现某个 App 功能异常/图片裂/加载不出，
#          就把对应域名加到这里，重跑构建，或直接写进你私人的 include 文件
#          （见 README「私人覆盖」一节，那条路不用重跑构建）。
# ============================================================================
