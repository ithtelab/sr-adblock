# ============================================================================
#  默认排除解密的域名（银行 / 券商 / 支付 / 常用办公）
#
#  这些域名**不会被 HTTPS 解密**。原因有两类：
#    1. 安全：涉及钱和身份，不该让手机上的 App 去解密处理
#    2. 兼容：它们普遍有证书固定（certificate pinning）与风控检测，
#       解密后会导致登录失败、白屏、强制退出
#
#  这份名单会被写进 dist/module/mitm-exclude.srmodule 的**默认参数**，
#  所以你把那个模块装上就自动生效，不需要改任何文件。
#  想增删：手机上装好模块后，点它的「编辑参数」直接改（改完不用担心被覆盖）。
#
#  ⚠️ 代价：被排除的域名不做解密，所以**依赖解密的重写规则对它们无效**
#     （比如东方财富的开屏广告那条重写）。域名层的拦截不受影响，照样生效。
#     你要某个 App 的去广告效果 → 把它的域名从这份名单里删掉。
#
#  语法：一行一个；`-` 前缀由构建时自动加，不用自己写。
#        可以用 *. 通配，例如 *.example.com
# ============================================================================
