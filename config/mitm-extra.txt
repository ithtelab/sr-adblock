# ============================================================================
#  手动开启解密的主机名（可选）
#
#  什么时候用：某个 App 的广告没去掉，而构建报告里显示它的主机名被
#  「金融守卫」拦下了（银行/券商/支付类默认不自动开解密，因为可能让你登录不了）。
#  你确认这个 App 解密没问题后，把主机名加到这里，它就会被写进模块的 MITM 列表。
#
#  语法：一行一个主机名，支持 * 通配。空行和 # 注释忽略。
# ============================================================================

# 示例（默认注释）：
# api.futunn.com
# m.airchina.com.cn
