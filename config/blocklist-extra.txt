#  自己额外要拦的域名（可选）
#
#  与 allowlist.txt 相反：这里是你自己加的拦截项，构建时会并进最终产物。
#  语法与 DOMAIN-SET 一致：
#    域名.com        精确匹配
#    .域名.com       含子域匹配（推荐，广告域名大多要连子域一起拦）
#
#  什么时候用：某个 App 的广告域名不在任何上游名单里，你想自己补上。
#  更推荐的做法是直接给上游提 PR / issue；这里适合你自己的私有补充。
# ============================================================================
